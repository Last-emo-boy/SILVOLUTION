        设计记忆
        从每一次规划器的动作里提炼出的教训，按后续运行采纳后的结果打分。规划器按情境和文本检索（对全部教训做 BM25，同生成器/同器件优先；来自其他组合的命中标为"迁移"）。
        
      
        
      
        
    
        
    
        
      
        回归基准
        回归套件：每个用例按标签分列（golden = 每个用例已知最佳设计重新实测，不用规划器；nightly = 默认规划器；planner-pro = DeepSeek V4 Pro；agent = 通过对话驱动；knob / newgen = 手动）
        
      
        
    
        
    
        
      
        设计目录
        到目前为止实测过的每个生成器 × 器件：已验证的点（行为级 + 网表仿真通过、能放下）、Pareto 前沿上最快和最小的设计、最近一次运行。在对话里要一个已有器件上的设计，它会从这些点起步。
        
      
        
    
        
    
        
      
        生成器提案
        智能体以 diff 形式提出的生成器改动；每一份都经过门禁（发射并展开所有预设、行为级仿真、未改动 IR 的形式等价、变异分数），可选 A/B 实测。不会自动合并：由操作员执行 deploy/merge-proposal.sh <id>
